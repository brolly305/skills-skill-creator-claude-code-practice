# Musashi learning log

One entry per learning cycle: a project from phase 0 to a phase 5 verdict. This log
is what the skill's governance triggers count. The revision trigger reviews the
skill after 10 cycles, judged on the retention results recorded here. The trust
trigger needs 5 completed cycles with documented application results.

Abandoned cycles count. Record them honestly; they're as informative as finished ones.
