# The Interview Prompt — HOL

Use this prompt to start any Claude task. Paste it, fill in the brackets, and Claude will ask the right questions before producing anything.

---

## The Prompt (copy and use this)

```
I want to [TASK] so that [GOAL].

Read my HOL folder (about-me.md, voice-profile.md, anti-ai-writing-style.md, global-instructions.md) then ask me clarifying questions using AskUserQuestions before you produce anything. Refine your approach with me as we go. Do not start writing until I've confirmed the direction.
```

---

## Examples of How to Fill It In

**Writing outreach to a prospect:**
> I want to write a first outreach message to a local landscaping company so that I can get a 15-minute conversation about their Google presence.

**Creating content:**
> I want to write 4 Google Business Profile posts for a property cleanout company so that their profile looks active and professional to anyone who finds them.

**Building a sales script:**
> I want to create a simple talk track for in-person conversations with local business owners so that I can explain what HOL does without sounding like a salesperson.

**Setting up a client:**
> I want to build a checklist for onboarding a new HOL client so that I don't miss any setup steps and the process takes under 4 hours.

**Planning next steps:**
> I want to map out my first 30 days with HOL so that I can get my first paying client while still working full-time at Tate & Lyle.

---

## Why This Works
Pasting this prompt forces Claude to read your context first, ask what it doesn't know, and confirm direction before producing anything. You get one usable output instead of five generic ones.
